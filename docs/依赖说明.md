# 依赖说明（交接用）

> 一句话：**运行时零依赖**。浏览器打开 `index.html`（或 `dist/offline.html`）即可运行，
> 不需要 npm install、不需要构建、不需要后端。

## 一、运行时（App 本体）

| 依赖 | 版本 | 用途 | 缺失时的行为 |
|---|---|---|---|
| 浏览器 Service Worker | — | 离线缓存 app shell | `file://` 下自动跳过，功能不受影响 |
| Web Speech API（可选） | — | 桌宠语音朗读 | 不支持则静默降级为纯文字气泡 |
| Geolocation API（可选） | — | 跑步 GPS 轨迹 | 拒绝授权则跑步页只显示手动统计 |
| BarcodeDetector（可选） | Chrome/Edge Android | 条码识食物 | 不支持则隐藏条码入口，走其它匹配路径 |
| createImageBitmap / OffscreenCanvas（可选） | — | 拍照压缩走快路径 | 老浏览器自动回落 Image+canvas |
| 网络（可选） | — | B 站嵌入播放器 / OpenFoodFacts / OSM 瓦片 / AI 识别代理 | 全部有降级路径，核心功能离线可用 |

数据存储：`localStorage['boji_v7']`（纯本机，无账号、无云端同步）。

## 二、构建与自检（仅开发时需要）

| 工具 | 版本 | 用途 |
|---|---|---|
| Node.js | 22.x | 跑自检与构建脚本 |
| jsdom | dev | `tools/selfcheck-functional.js` 的行为级回归（需 `NODE_PATH` 指到含 jsdom 的 node_modules） |
| qrcode | dev | 重新生成下载二维码（`npm i qrcode`） |
| Chrome | 任意较新版本 | `--headless --screenshot` 做视觉验收 |
| Python | 3.x（标准库） | `tools/mkzip.py` 打交接包（零第三方依赖） |

常用命令：

```bash
# 语法门禁
node --check app.js && node --check sw.js
# 全量自检（当前 55 功能 + 196 攻击 = 251 项）
node tools/selfcheck.js
# 重新构建离线单文件（改完源码后必须重跑）
node tools/build-offline.js
# 打交接包
python tools/mkzip.py
```

> jsdom 运行方式：`NODE_PATH=<含 jsdom 的 node_modules> node tools/selfcheck.js`

## 三、外部资源（会联网，但都有兜底）

| 资源 | 地址 | 兜底 |
|---|---|---|
| 动作/科普视频 | B 站（官方嵌入播放器） | 弹层内「原站 ↗」或「本地视频」离线播放 |
| 食物在线库 | world.openfoodfacts.org | 弱网重试 1 次 → 历史/本地库匹配 |
| 地图瓦片 | tile.openstreetmap.org | 默认关闭，轨迹形状图离线可用 |
| AI 食物识别 | 用户自建代理（`server/`） | 未配置则走条码/历史/本地库，绝不假装识别 |
