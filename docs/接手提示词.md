  没有 PAT 就不要尝试推送，改为交付文件并说明手动上传步骤。
- 回答用中文，改动后给出"改动清单 + 自查结果 + 未决问题"。

现在请从 docs/待办与未决问题.md 的 P0/P1 中挑一项我指定的任务开始（或先复跑自检确认基线健康），
