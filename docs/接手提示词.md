## v1.2 接手补充（2026-10-01）

- 仓库 / 线上不变：https://github.com/wage98/boji-diary ｜ https://wage98.github.io/boji-diary/
- 自检规模已到 **功能 55 + 攻击 196 = 251 项**（`node tools/selfcheck.js`），v1.2 新增 Q/V/W/X/Y 五组。
- 新增文件：`tools/build-offline.js`（离线单文件构建器，产物 `dist/offline.html`）、
  `训练日记-下载二维码.png`。构建产物在 `dist/`，改完源码要重跑 `node tools/build-offline.js`。
- 关键设计决策（不要轻易回退）：
  1. Service Worker 是**缓存优先**（stale-while-revalidate），别改回网络优先——那就是"启动转圈"的根因；
  2. 视频走 B 站官方**嵌入播放器**（`bilibiliEmbed()`），不要改回 `window.open` 跳转；
  3. 照片桌宠默认**保留原图五官**（`petPhotoFx='natura'`），卡通叠加只是可选；
  4. `photoPetSVG` 的 `<svg>` 必须带 `width/height`，去掉就会糊（jsdom 测不出，真机会糊）；
  5. 语音生命周期靠 `voiceSync()`：面板打开即停，回桌面续播，别绕过它直接 speak。
- 自检夹具对**跨月敏感**：涉及"本月"的种子与断言必须按当前日号选偏移（见 selfcheck-functional.js 顶部），
  不要改回固定 -1/-2。
