# 视频来源核对清单（v1.2.2）

本文档列出 App 内**全部外链视频**，供逐条核对。播放方式为 App 内嵌 B 站官方播放器（`player.bilibili.com`），**不跳转**、不留站外记录。

## 取链与审验规则（v1.2.2 重筛）

1. 来源：B 站搜索（解析服务端渲染页拿 BV + 真实标题 + 时长；再用官方 `view` 接口逐条复核活性与秒级时长）；
2. **硬约束 · 时长 ≤ 95 秒**：只教该动作本身，去掉铺垫、寒暄、训练计划等冗余；
3. **硬约束 · 直给教学**：标题须含该动作核心名词 + 教学信号（教学/动作/做法/标准/保姆级/拆解/纠错/分钟学会等）；
4. **硬约束 · 变体精确**：地板版不混椅子版、哑铃版不混杠铃版、单臂/双手不混用、绳索版不混弹力带版；
5. **排除词**：合集、跟练、系列、计划、挑战、打卡、多动作混剪、「第 N 天」训练日志、游戏实况等一律淘汰；
6. 界面显示的 label 就是视频**真实标题**，点开前即可核对内容。

> 局限（如实说明）：脚本核对的是**标题文本 + 时长 + 链接活性**，无法观看视频内容。个别视频若日后被 UP 主更换内容，只能靠用户反馈发现；链接失效可在本条规则下重新检索替换。
