# 视频来源核对清单（v1.1）

本文档列出 App 内**全部外链视频**，供逐条核对。

## 取链与审验规则

1. 来源：B 站搜索结果（解析服务端渲染页），取 BV 号 + 真实标题；
2. **硬约束**：视频标题必须包含该动作的核心名词（如「划船」「卧推」「深蹲」），否则淘汰；
3. **排除词**：命中游戏实况、生化课程、营销长标题等的一律淘汰（曾据此淘汰「重装机兵…蛋白质宫殿」这类游戏视频）；
4. 打分：核心名词 +6/个、教学信号（教学/详解/科普/原理）+4、标题简短 +3，取最高分；
5. 界面显示的 label 就是视频**真实标题**，点开前即可核对内容；
6. 只做跳转，不在 App 内嵌播放，不存在二次分发。

> 局限（如实说明）：脚本只能核对**标题文本**，无法观看视频内容。若某条视频日后被删除或换内容，链接会失效。
