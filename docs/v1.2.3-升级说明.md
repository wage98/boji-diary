## 三、不借鉴项及理由（有判断地取舍）

| V2 能力 | 不借鉴原因 |
|---|---|
| IndexedDB + ES Modules 数据内核（`data-layer.js` 85KB） | 会换掉 `localStorage['boji_v7']` 事实来源，破坏数据/接口兼容，并引入新脚本依赖 |

## 五、兼容要求与实现约束

- `localStorage['boji_v7']` **键不变**；`checkins / weights / planEdits / exLast / myEx / settings` 等既有字段一个不动、语义不变。
- 只新增**可选**字段 `STATE.exReps[日期][动作下标] = { r: 完成次数, kg: 当时重量 }`；老版本备份无此字段 → 空对象；脏值（字符串/数组/负数/超大）一律清洗，不回填、不参与判定。
- `overloadSuggestion()` 返回结构**向后兼容**：`cur / next / ready` 恒存在，新增字段为增量。
- `planEdits / exLast / weights` 仍按动作数组**下标**存储 → 本轮**不改动作顺序、不增删动作**，避免老用户已存组数与重量错位。
- 判定只依据**用户真实填写的完成次数 + 已打卡记录**（`checkins[k].at`）；未填就如实标注「还没有完成次数记录」，**绝不伪造次数、重量、日期或来源**。
- 加重后旧达标记录因重量快照不同自动退出判定，不会反复建议加重；历史记录保留不删。
- **零新依赖、零新框架**：纯 vanilla JS，未引入 `data-layer.js` / `release-config.js` 或任何外部脚本。
