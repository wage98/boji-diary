# v7.11 后续优化与改进方向清单（对标开源/成熟产品）

> 对标对象（2026-09 检索确认）：VPet-Simulator（WPF，三层架构 + MOD 生态 + Steam 创意工坊 1.2w+ MOD）、DyberPet（PySide6，养成数值/番茄钟/LLM 对话分支/JSON 模组）、DesktopPet（状态机 + 桌面物理：爬墙/天花板/抛掷）、desk-tamagotchi（可插拔 sprite + config.json + 能量系统）、Shimeji（经典行为库：爬边/拖拽抛出/睡觉）。食物 AI 参考：Nutrition5k、Im2Calories 等公开研究方向的"图像→份量→营养"管线思路。
> 原则：纯前端 PWA 不妥协（无后端也能用），每项标注优先级与可回退性。

## A. 功能
| # | 方向 | 说明 | 优先级 | 参考 |
|---|------|------|--------|------|
| A1 | 桌宠行为库扩充 | 爬左右边缘行走、被拖拽抛出后物理坠落、打盹位置随机——已有 edge-t/flip/爱心基础，缺"状态机化" | P1 | Shimeji / DesktopPet 物理行为 |
| A2 | 养成数值 | 连续打卡映射"好感度/等级"，等级解锁新台词与配饰（纯本地） | P1 | DyberPet 数值养成 |
| A3 | 番茄钟+专注陪伴 | 桌宠在专注时段安静陪伴，结束时庆祝（复用现有 mood 系统） | P2 | DyberPet 生产力工具 |
| A4 | 皮肤 MOD 化 | 把 PET_SKINS/PET_THEME 开放为 JSON 皮肤包（用户可导入自定义配色/纹样） | P2 | VPet MOD / desk-tamagotchi config.json |
| A5 | 端侧份量参考物 | 拍照引导页提示"放一枚一元硬币/标准餐盘在旁"，提升克数估计精度 | P1 | Nutrition5k 份量标注思路 |
