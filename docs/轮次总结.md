## 2026-09-27 · 第三轮（v7.8：AI 真识别 + 自定义动作 + 体重曲线 + 自绘形象）

## 2026-09-27 · 第二轮（v7.7 拍照识别修复 + Keep 风格改版）

**本轮改动**
- 识别流程重做（v7.7）：拍照（`data-photo`）与相册（`data-album`）分离为两个入口——修复旧版写死 `capture="environment"` 导致相册入口不可用的问题。
- 新增三级匹配识别 + 置信度体系：条码（BarcodeDetector→OpenFoodFacts v2，0.95）/ 在线库（0.8）/ 历史记录（0.75，`favFoods()` 按频次统计常吃食物）/ 本地库（精确 0.7、模糊 0.45）。结果卡显示徽章（高/中/低/无 + 依据来源），<0.6 强制黄色警示；无匹配红色提示 + 手动搜索入口。诚实边界不变：不做虚假端侧 AI 图像识别。
- 性能：`compressImage` 异步化（`createImageBitmap` + `OffscreenCanvas` 优先，老浏览器回落 Image+canvas）；条码检测用 640px 高清副本，存档缩略图仍 160px。
- 稳定性：`queryOFF` 弱网自动重试 1 次（900ms 间隔）；失败文案分类（超时/网络/未收录）；加载骨架 shimmer；热量覆盖夹取 ≤5000、克数 1–2000、份数 0.5–50；单份热量 >4000 拒绝写入（结果二次校验）；记录新增 `cf` 字段，记录流内 ⚠ 标记低置信度条目。
- Keep 风格：饮食页新增「今日热量」汇总卡（大数字 + 热量/蛋白进度条）；每餐卡主行动按钮「📷 拍下这一餐」+ 次按钮「🖼 相册 / ✍ 手动」；识别结果页 CTA「✓ 确认添加」。
- 自检：攻击式新增 G1–G13（13 项），D1/D2 因重试机制调整等待时间至 1350ms；当前 **功能 41 + 攻击 64 = 105 项全 PASS**。
- 版本：app.js v7.7、SW 缓存 `boji-v7-7-20260927`；`docs/自绘形象方案对比.md`（推荐方案 A 分层 SVG）。
