# 轮次总结（协作接续用 · 每轮追加，最新在上）

## 2026-09-27 · 第四轮（v7.9：桌宠颜值重制 + AI 识别打磨 + 知识库扩充 + 录入摩擦）

**上一轮接续点**：①AI 识别需部署 Worker/填 Key ②桌宠 SVG 观感待真机验证 ③P1=力量曲线/围度/捏桌宠。

**本轮改动**
- **桌宠颜值重制（核心）**：`nahidaSVG` 全部重写——Q 版头身比 1.35:1、包子脸、渐变虹膜（三层径向渐变+双高光）、定向睫毛（含外眼角翘尾）、双层头发（后发+刘海+鬓发+呆毛）、发丝线与发缘描边（消除「头盔感」）、径向渐变腮红、泡泡袖连衣裙+腰带金扣+小皮鞋、底部接触阴影。配色集中到 `PET_THEME`（捏桌宠只需改主题对象）。**用 Chrome headless 截图逐版肉眼验收**（发色/刘海/腮红共迭代 2 版）。
- **桌宠交互**：随机眨眼（3–7s，只换眼型保留嘴型与腮红，官方皮肤自动跳过）；连点彩蛋（5 秒内点 5 次 → 星星眼+痒痒台词）。
- **AI 识别打磨**：prompt 升级（中餐/合并多食物、可食部分规则、常见份量锚点、宏量自洽 ±20% 约束、confidence 语义锚定），前端与 `server/worker.js` 同步；同图内存缓存（Map，上限 12 条）避免重开面板/重试重复扣调用；失败新增「🔄 重试」按钮；错误分类提示（401/403→检查口令、429→稍后再试、5xx→服务暂不可用、超时/网络分开）。
- **知识库 42→62 条**：新增训练进阶（卧推没感觉/俯卧撑降阶/引体/腹肌/手臂/背部/硬拉/肩弹响）、营养实战（食堂/夜宵/咖啡/奶茶零食/蛋白不够）、计划瓶颈（哑铃太轻/每组次数）、恢复信号（抽筋/头晕/泡沫轴）、身体数据（体脂秤误差/经期/体重不涨），均带证据等级。匹配升级：问句归一化（去标点/语气词）。修掉一个真实缺陷：「喝水重要吗」条目的泛关键词 `喝` 会抢走「奶茶能喝吗」，已收窄为 `喝水/饮水/缺水/补水` 并加 I5 断言防回退。
- **数据化回答新增 3 分支**：体重趋势（结合 `bodyWeights`，空数据引导记录；涨/降/稳都有解读）、本周统计（周一起已练天数+完成动作数）、吃什么建议（按今日蛋白缺口推荐食物）。**注意**：体重趋势分支必须排在泛化的「体重」分支之前（测试发现顺序错误会命中档案文案）。
- **录入摩擦**：饮食页「⏩ 一键复制上次」（近 7 天同餐最近一次，深拷贝并去掉照片缩略图防 localStorage 膨胀，仅在该餐为空时显示）。
- **审验**：新增 I1–I10（含用 Chrome headless 截图前先过的 11 帧 SVG 有效性断言）。**功能 41 + 攻击 98 = 139 项全 PASS**。版本 v7.9、SW `boji-v7-9-20260927`。

**遗留问题**
- 桌宠观感已用截图验收至合格，但**最终以你手机上的实际观感为准**；不满意随时说，参数化改起来快。
- AI 识别仍需你部署 Worker 或填 Key；误差实测（拍 10 张记录偏差）依然待做。
- 眨眼帧/彩蛋是逻辑级测试（函数存在+SVG 有效），真机动画节奏需肉眼确认。

**下一步计划**
1. 你验收形象与功能 → 反馈微调（发色/裙色/表情可按 PET_THEME 快速改）。
2. 部署 Worker → 实拍 10 张记录 AI 真实误差 → 调 prompt 与置信度阈值。

## 2026-09-27 · 第二轮（v7.7 拍照识别修复 + Keep 风格改版）

**本轮改动**
- 识别流程重做（v7.7）：拍照（`data-photo`）与相册（`data-album`）分离为两个入口——修复旧版写死 `capture="environment"` 导致相册入口不可用的问题。
- 新增三级匹配识别 + 置信度体系：条码（BarcodeDetector→OpenFoodFacts v2，0.95）/ 在线库（0.8）/ 历史记录（0.75，`favFoods()` 按频次统计常吃食物）/ 本地库（精确 0.7、模糊 0.45）。结果卡显示徽章（高/中/低/无 + 依据来源），<0.6 强制黄色警示；无匹配红色提示 + 手动搜索入口。诚实边界不变：不做虚假端侧 AI 图像识别。
- 性能：`compressImage` 异步化（`createImageBitmap` + `OffscreenCanvas` 优先，老浏览器回落 Image+canvas）；条码检测用 640px 高清副本，存档缩略图仍 160px。
- 稳定性：`queryOFF` 弱网自动重试 1 次（900ms 间隔）；失败文案分类（超时/网络/未收录）；加载骨架 shimmer；热量覆盖夹取 ≤5000、克数 1–2000、份数 0.5–50；单份热量 >4000 拒绝写入（结果二次校验）；记录新增 `cf` 字段，记录流内 ⚠ 标记低置信度条目。
- Keep 风格：饮食页新增「今日热量」汇总卡（大数字 + 热量/蛋白进度条）；每餐卡主行动按钮「📷 拍下这一餐」+ 次按钮「🖼 相册 / ✍ 手动」；识别结果页 CTA「✓ 确认添加」。
- 自检：攻击式新增 G1–G13（13 项），D1/D2 因重试机制调整等待时间至 1350ms；当前 **功能 41 + 攻击 64 = 105 项全 PASS**。
- 版本：app.js v7.7、SW 缓存 `boji-v7-7-20260927`；`docs/自绘形象方案对比.md`（推荐方案 A 分层 SVG）。
