# 薄肌日记 · 架构说明与模块职责（v7.6）

> 本文件是记忆文档的项目镜像，供新对话/新接手者直接读取，无需额外背景。

## 一、形态与定位
- **纯前端单页 PWA**：`index.html + app.js + styles.css + sw.js + manifest.json`，无构建、无框架、无后端。
- **数据 100% 存本机 localStorage**（键 `boji_v7`），无账号、无云同步——这是明确的隐私取舍，不是缺陷。
- **定位**：居家哑铃增肌方案 + 手机桌面常驻二次元桌宠（纳西妲）陪伴；桌宠既是主界面也是反馈通道。
- **线上**：https://wage98.github.io/boji-diary/ （GitHub Pages，公开仓库 `wage98/boji-diary`，分支 `main`）。

## 二、目录职责

| 路径 | 职责 |
|---|---|
| `index.html` | App 外壳：手机 mockup、桌宠浮层、面板容器、弹窗（引导/完成/食物校正/休息计时）、toast |
| `app.js` | 全部逻辑（约 1100 行）：数据模型、桌宠引擎、导航栈、四个模块页、助手、导出导入 |
| `styles.css` | 设计 token + 组件样式 + 移动端整屏适配（`@media max-width:560px` 丢装饰外壳） |
| `sw.js` | Service Worker：页面请求**网络优先**（保证打开即新版），静态资源缓存优先 |
| `manifest.json` / `assets/` | PWA 元数据与自绘图标；`assets/CREDITS.md` 为角色素材溯源 |
| `docs/` | 文档（工作日志、经验总结、竞品差距、审验记录、本文件、待办、接手提示词） |
| `tools/` | 可复现验证脚本 `selfcheck.js`（jsdom） |
| `_archive/` | **本地归档**（旧版 React 源码、未使用大图、历史二维码），已在 `.gitignore` 排除，不入库 |

## 三、数据模型（`STATE`，键 `boji_v7`）

```js
{
  profile: { name, height, weight, dumbbell, avatar(dataURL|null) },
  isFirstLaunch: bool,
  checkins: { 'Y-M-D': { ex: { 动作序号: true }, at } },   // 打卡
  weights:  { 'Y-M-D': { 动作序号: 'kg' } },               // 当次重量
  meals:    { 'Y-M-D': { 0|1|2|3: [ { n,p,c,f,q,photo,kcalFix? } ] } },  // 早/午/晚/加餐
  water:    旧版「杯」(遗留),  waterMl: 今日饮水量(ml),
  scores:   { 'Y-M-D': { feel, energy, sat, at } },        // 每日 1-5 星评分
  planEdits:{ dayType: { 动作序号: { sets, reps } } },     // 计划编辑
  exLast:   { dayType: { 动作序号: kg } },                 // 上次重量（渐进超负荷）
  editPlan: bool, selDate: 'Y-M-D'|undefined,
  petPos(遗留), petDock:{edge:'left'|'right', off}, petMood, lastPetTouch
}
```

**迁移约定**：任何结构变更必须写迁移代码（例：v7.5 `water`(杯) ×250 → `waterMl`），并补一条脏数据用例。

## 四、模块职责（`app.js` 内分区）

| 分区 | 关键函数 | 说明 |
|---|---|---|
| 训练计划 | `PLANS` / `DAY_TYPES` / `getDayType` | 4 训练日 23 个**居家哑铃**动作，B 站章节时间戳外链可自验 |
| 知识库与助手 | `KB`(42 条) / `nahidaReply` / `dataReply` / `CTX` | 规则匹配 + 多轮上下文追问 + 结合本机数据回答；无把握明确说不确定 |
| 食物库 | `EST_LIB`(81 项) / `queryOFF` (OpenFoodFacts) | 本地估算为主，在线查询补充；失败回落本地库 |
| 桌宠引擎 | `setMood` / `say` / `applyDock` / `dockToNearest` | 8 种情绪、打字机气泡、左右缘直立探头吸附（不旋转） |
| 导航栈 | `NAV` / `navOpen` / `navUIClose` / `popstate` | 返回键关层，无层时连按两次退出（v7.4 P0） |
| 训练模块 | `renderTraining` / `finishDay` / `startRest` | 周历 + 动作卡 + 组间计时 + 渐进超负荷建议 |
| 饮食模块 | `renderDiet` / `openPhotoIntake` / `openFoodSheet` | 饮水 ml；拍照留档 + 估算 + 全字段校正 |
| 数据模块 | `renderData` | 统计格 + 月历（✓/评分）+ 每日评分 + 近 7 日柱状图 |
| 我的 | `renderProfile` | 档案实时编辑（oninput 即存）、头像上传压缩、导出导入 |
| 导出 | `exportJSON` / `exportCSV` / `importJSON` | CSV 带 UTF-8 BOM（Excel 不乱码） |
