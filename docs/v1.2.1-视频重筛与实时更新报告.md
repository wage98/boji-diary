## 二、手机端实时更新

原机制只有 SW 后台更新，用户要"关掉再打开"才拿到新内容。本次改动：

1. **升版**：`APP_VERSION` 1.2.0 → **1.2.1**，SW `CACHE` → `boji-1-2-1`（activate 自动清旧缓存）；
2. **`sw.js` 新增 `__upd` 旁路**：带该参数的请求强制走网络、不进缓存——
   否则 SW 会把缓存的旧 app.js 返回给版本检查，永远发现不了新版本（这是能否"实时"的关键）；
3. **`checkAppUpdate()`**：空闲时 + 「回到前台」时拉线上版本号比对，不一致弹出
   **「发现新版本 vX，点击立即更新」** 悬浮条；点击后注销 SW、清全部缓存、刷新页面；
   一分钟内不重复查询；无 `fetch` 的老环境静默跳过；
4. 兜底链路仍在：即使更新条没弹，新 SW 安装后也会接管并预取新壳，第二次打开即最新。
