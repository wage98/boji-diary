# 「小蛛」形象差异说明（vs 漫威蜘蛛侠 / 早期版 vs 现版）· v7.11

> 目的：小蛛以"蜘蛛侠"为灵感，但必须与漫威官方形象保持**明确可辨识的差异**，规避版权/商标风险；同时锁定早期版与现版各自的特征，后续迭代不再漂移。全部自绘矢量（分层 SVG），未使用任何官方素材。

## 一、与漫威官方蜘蛛侠的差异对比

| 维度 | 漫威官方蜘蛛侠 | 小蛛·早期版（v1） | 小蛛·现版（v2） |
|------|----------------|--------------------|------------------|
| **配色** | 深红 + 藏蓝（高饱和、明暗对比强） | 红 `#d93a3a` + 蓝 `#3d6bd8`（更亮更卡通，非官方色值） | **珊瑚红 `#e2694a` + 松绿 `#2f8f7a`**（整体暖色系，与红蓝体系彻底区分） |
| **面具纹样** | 黑色放射蛛网（粗线、高密度、覆盖全脸） | 细线放射蛛网（低透明度，仅装饰） | **斜向网格纹**（非放射蛛网，纹样语言完全不同） |
| **标志（胸口）** | 红底黑蜘蛛徽记 | 简化小蜘蛛点纹（非蜘蛛徽记造型） | **哑铃形胸标**（健身主题标志，与蜘蛛无关联） |
| **眼罩** | 大白镜片、上挑锐利、黑粗边 | 圆润椭圆白镜片、细边 | 圆润椭圆 + 淡青白 `#f4fbf8`、更"呆萌" |
| **身形比例** | 修长成年人体型 | 头身比约 1:0.6（Q 版化） | **头身比约 1:0.5，整体放大 7% 更矮更圆**（幼态 Q 版，与"运动员体型"拉开） |
| **表情系统** | 无面部表情（面罩） | 10+1 情绪帧（眼/嘴/腮红/特效参数化） | 同左 |

**结论**：现版（v2）在配色体系、纹样语言、胸标符号、身形比例四个维度均与官方形象形成明确差异；早期版（v1）虽更接近灵感原型，但配色非官方色值、无蜘蛛徽记、Q 版化处理，仅作内部保留与对比展示。**对外宣传与截图默认使用 v2**（App 默认皮肤已设为 spiderV2）。

## 二、早期版 vs 现版（参数锁定）

两版由同一套分层 SVG 函数按 `SPIDER_THEME` 参数化生成，差异**只**集中在以下 4 项参数（改版只动主题，不动绘制逻辑，保证特征一致不漂移）：

| 参数 | v1 早期版 | v2 现版 |
|------|-----------|---------|
| `red / redD`（主色/暗部） | `#d93a3a` / `#a52222` | `#e2694a` / `#b34a2f` |
| `teal`（下装） | `#3d6bd8`（蓝） | `#2f8f7a`（松绿） |
| `web`（头纹样） | `radial` 放射蛛网 | `diag` 斜向网格 |
| `emblem`（胸标） | `spider` 小蜘蛛点纹 | `dumbbell` 哑铃 |
| `body`（身形比） | `1.00` | `1.07`（更圆更矮） |
