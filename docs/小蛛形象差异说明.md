# 「小蛛」形象差异说明（vs 漫威蜘蛛侠 / v1·v2·v3 参数锁定）· v8.0

> 目的：小蛛以"蜘蛛侠"为灵感，但必须与漫威官方形象保持**明确可辨识的差异**，规避版权/商标风险；同时锁定三个版本各自的特征，后续迭代不再漂移。全部自绘矢量（分层 SVG），未使用任何官方素材。

## 〇、v8.0 变更摘要（按视频款式重制）

参考视频逐帧解析后确认：**现版 v2 的四项「去红蓝化」改动（珊瑚红 / 松绿 / 斜网格 / 哑铃胸标）方向恰好与视频相反**，这正是"不像视频里那个"的根源。v8.0 新增 **v3「视频同款」** 作为默认皮肤，把这四项改回视频实测值；v1 / v2 全部保留可切换，切换不丢状态。

## 一、与漫威官方蜘蛛侠的差异对比

| 维度 | 漫威官方蜘蛛侠 | 小蛛·早期版（v1） | 小蛛·现版（v2） | **小蛛·视频同款（v3，默认）** |
|------|----------------|--------------------|------------------|------------------------------|
| **配色** | 深红 + 藏蓝（高饱和） | 红 `#d93a3a` + 蓝 `#3d6bd8`（更亮更卡通，非官方色值） | 珊瑚红 `#e2694a` + 松绿 `#2f8f7a`（暖色系，与红蓝体系彻底区分） | `#c92848` + `#344383`（**接近官方色系，靠下面的纹样/胸标/身形拉差异**） |
| **面具纹样** | 黑色放射蛛网（粗线、高密度、覆盖全脸） | 细线放射蛛网（低透明度，仅装饰） | 斜向网格纹（非放射蛛网） | 放射蛛网，但**限 6 条主干 + 3 圈同心环，低密度**，不做全覆盖 |

| **地面阴影** | 依场景 | 有 | 有 | **无**（悬浮） |

### 版权护栏（v3 必守，缺一不可）

1. 胸标坚持**自绘简化造型**：直线折角腿 + 瘦长椭圆躯干，与官方弧线造型明确不同。
2. 面罩蛛网**限 6 条主干、3 圈同心环**，不做官方那种高密度全覆盖。
3. **不使用任何官方 Logo、字体或官方素材文件**；全部为本仓库自绘 SVG。
4. 全身仅红 / 蓝 / 白 / 深色描边四色，**无渐变、无立体高光**。
5. 差异程度是否可接受，最终由用户确认（规格书第六节已标注此风险）。

> ⚠ **风险如实记录**：按视频款式重制后，v3 与官方形象的可辨识差异相比 v2 **显著缩小**（主色、纹样语言、胸标三项原本的差异化设计都回到"接近原型"）。这是用户明确要求的方向，已在上表用护栏尽量保留差异，但不能宣称"与官方无关"。v2 保留在注册表里，如需更强的差异化可随时切回。

## 三、与规格书的一处偏差（如实记录）

规格书 3.2-② 建议把红蓝分界由 `y=107` **上提至 `y≈98`**。落地时发现该值与规格书 3.2-③「蜘蛛徽记位于红色胸区中央」**互相矛盾**：

- 可见躯干区域只有约 `y 96–123`（头部圆形下沿 96，下腹底 123），共 27 个单位；
- 若分界上提到 98，红胸区只剩 2 个单位，胸标（包络高约 14）必然整体落进蓝色下腹区，与视频「胸红腹蓝」矛盾。

**处理方式**：分界保持 `y=107`，改为把胸标上移到中心 `y≈101`（包络 `y 94–108`），使其完整落在红胸区内。若你希望蓝区占比更大，可再权衡——但这会让胸标落入蓝区。
