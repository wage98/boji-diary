# 薄肌日记 · 纳西妲的居家哑铃健身桌宠

手机桌面常驻二次元桌宠（纳西妲）陪伴的**居家哑铃**增肌记录 App。纯前端 PWA，无构建、无后端、数据仅存本机。

- 在线体验：https://wage98.github.io/boji-diary/
- 版本：v7.9 ｜ 许可：个人使用（角色素材溯源见 `assets/CREDITS.md`）

## 目录职责

| 路径 | 内容 |
|---|---|
| `index.html` `app.js` `styles.css` `sw.js` `manifest.json` | App 源码（单页、无构建） |
| `assets/` | 图标与角色素材、`CREDITS.md` |
| `docs/` | 工作日志、经验总结、架构说明、竞品差距分析、审验记录、待办与未决问题、产品规划与工作流程、自绘形象方案对比、轮次总结、接手提示词 |
| `tools/` | 可复现自检脚本（jsdom）、形象预览生成、GitHub 推送脚本 |
| `server/` | 可选的 AI 识别代理（Cloudflare Worker），不启用时 App 完全离线可用 |
| `_archive/` | 本地归档（旧版源码/未使用素材/历史二维码），已 gitignore，不入库 |

## 功能速览

- **训练**：推/拉/腿/泵 4 日 23 个居家哑铃动作；组次与重量记录、渐进超负荷建议（+2.5kg）、组间休息计时、计划可编辑、B 站章节时间戳可自验。
- **自定义动作**（v7.8）：自建动作的**部位 / 组数 / 次数 / 休息 / 要点**，休息日也能练，重量与完成状态同样记录。
- **饮食**：饮水按 **ml** 计量；拍照 → **AI 视觉识别（可插拔，默认关闭）** / 条码 / 历史高频 / 在线库 / 81 项本地库；结果带**置信度徽章**，名称/份量/热量全字段可校正。
- **数据**：番茄 ToDo 式统计格、月历打卡视图（✓/评分）、每日训练评分（感受/体力/满意度）、近 7 日柱状图、**体重曲线（手写 SVG）**。
- **我的**：档案（昵称/身高/体重/哑铃）**实时编辑并即时影响建议重量与热量目标**；改体重自动记入曲线；头像可上传；AI 识别设置与连通性测试；JSON/CSV 导出与导入。
- **助手**：62 条带证据等级的知识库 + 多轮上下文追问 + 结合本机数据回答（今天练什么 / 蛋白够吗 / 本周统计 / 体重趋势 / 吃什么建议）。
- **桌宠**：10 种情绪 + 眨眼动画 + 连点彩蛋、打字机气泡、左右缘直立探头吸附、可拖拽；手机返回键关层不退出；**精致 Q 版分层 SVG 自绘皮肤（默认，零版权依赖，截图验收）+ 可切换官方素材**。

## 本地运行与验证

```bash
# 1) 语法门禁
node --check app.js && node --check sw.js

# 2) 安装自检依赖（一次性）
cd C:/Users/WaGe/.workbuddy/binaries/node/workspace && npm i jsdom --registry=https://registry.npmmirror.com

# 3) 跑自检（功能回归 41 项 + 攻击式自检 98 项）
node tools/selfcheck.js

# 4) 生成桌宠形象预览页（可选，用于肉眼验收自绘 SVG）
NODE_PATH=<jsdom 所在 workspace>/node_modules node tools/gen-pet-preview.js
```

推送（本机 git 协议被阻断，走 Git Data API）：
```bash
GH_TOKEN=<你的PAT> node tools/push.js "提交说明"
```

本地打开：`file://` 直接双击 `index.html` 即可（此模式下 Service Worker 不注册，功能不受影响）；
如需完整 PWA 行为，用任意静态服务器托管后以 `http://localhost` 访问。

## 部署

GitHub Pages 自动发布（推送 `main` 后约 1–3 分钟生效）。推送方式二选一：
1. REST contents API（需 PAT，`contents:write`）；
2. `git push`（需 PAT 且具备仓库写权限）。

Service Worker 对**页面请求采用网络优先**，因此手机下次打开即为最新版本，无需手动刷新或重新发版。

## 已知边界

- **AI 识别默认关闭**：真·图像识别必须调用云端视觉模型。v7.8 提供可插拔接入（自建代理 / OpenAI 兼容直连），未配置时明确降级为条码/在线库/历史/本地匹配，**不会返回编造结果**。部署方式见 `server/README.md`。
- **识别误差**：即便开启 AI，家常菜混合餐的估算误差仍可能在 ±15~35%，结果页强制可校正，UI 已如实标注。
- **条码识别**仅 Chrome/Edge 安卓支持（iOS 自动隐藏入口，手动路径完整）；OpenFoodFacts 大陆网络偶发不可达（已有重试 + 降级）。
- 数据仅存本机，换机请用导出/导入 JSON。
